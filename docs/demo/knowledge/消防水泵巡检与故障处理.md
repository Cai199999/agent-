# 消防水泵巡检与故障处理

## 适用范围

适用于住宅、写字楼、园区消防水泵房，包括消火栓泵、喷淋泵、稳压泵及配套控制柜。

## 日常巡检

1. 每日检查水泵房环境：无积水、无异味、照明正常、门禁可正常开启。
2. 查看控制柜电源指示、故障指示、手自动状态，正常应处于自动状态。
3. 查看进出水管压力表：消火栓泵出口压力通常保持在 0.35–0.60 MPa，喷淋泵按设计要求执行。
4. 检查泵体、法兰、阀门有无渗漏；检查电机温度与运行声音是否正常。
5. 每周手动盘车一次，确认泵轴转动灵活、无卡涩。
6. 每月进行一次主备泵切换测试并记录；每季度配合消防维保进行启泵试验。

## 常见故障

| 现象 | 可能原因 | 处理动作 |
|---|---|---|
| 控制柜故障灯亮 | 缺相、过载、热继电器动作 | 断电后检查电源与热继，复位前确认无短路 |
| 水泵不启动 | 手自动状态错误、压力开关未动作、控制回路故障 | 检查手自动、压力开关与控制回路，必要时转维保 |
| 泵体漏水 | 机械密封磨损、法兰垫片老化 | 关闭进出水阀，报维保更换密封/垫片 |
| 运行异响/振动 | 轴承磨损、叶轮异物、地脚松动 | 立即停泵，挂牌，通知维保检查 |
| 压力不足 | 止回阀内漏、叶轮磨损、管道漏点 | 检查阀门与管道，记录压力变化并报修 |

## 安全要求

- 严禁在未确认断电的情况下打开控制柜。
- 严禁无水空转；启泵前确认水池液位和阀门状态。
- 涉及消防系统停用必须履行审批并设置临时防护。
- 发现火情、冒烟、漏电时，先确保人员安全并报警，不得盲目操作。

## 升级与转人工

出现以下情况必须立即转人工并通知消防维保：

- 主备泵均无法启动；
- 控制柜冒烟、焦味或明显放电；
- 消防管网大面积失压；
- 现场已经发生火情或人员受伤。

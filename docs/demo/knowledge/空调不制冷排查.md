# 空调不制冷排查

## 适用范围

适用于办公楼、住宅公共区域的分体空调、多联机与风机盘管。

## 快速判断

1. 确认空调是否通电、遥控器/面板是否显示故障码。
2. 确认模式为制冷，设定温度低于室温 2℃ 以上。
3. 检查过滤网是否积尘、出风口是否有风。
4. 询问是否为单个房间还是整层/整栋，判断是末端问题还是主机问题。

## 常见原因

| 现象 | 可能原因 | 处理动作 |
|---|---|---|
| 出风但不凉 | 过滤网堵塞、缺冷媒、压缩机未启动 | 清洗滤网；观察外机是否运行；缺冷媒转维保 |
| 完全无风 | 电源故障、风机故障、控制面板故障 | 检查电源与面板，报维保 |
| 外机频繁启停 | 冷凝器脏堵、电压不稳、过热保护 | 清理冷凝器周围杂物，检查电压 |
| 室内机漏水 | 排水管堵塞、冷凝水盘积水 | 疏通排水管，做好接水防护 |
| 显示故障码 | 传感器/通信/压缩机保护 | 记录故障码，按品牌手册处理或转维保 |

## 安全与升级

- 涉及外机高空作业、冷媒操作、电气检修时必须由持证人员处理。
- 外机冒烟、焦味、漏电时立即断电并报修。
- 整层/整栋不制冷、机房精密空调故障、影响消防或电梯机房散热时优先升级。

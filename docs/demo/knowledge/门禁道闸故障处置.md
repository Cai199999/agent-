# 门禁与道闸故障处置

## 适用范围

适用于楼宇大堂门禁、单元门、地下车库道闸、访客通道闸机。

## 报修前确认

1. 确认是单个门禁还是整栋/整个区域失效。
2. 确认刷卡、密码、人脸、二维码等不同方式是否都不可用。
3. 确认门磁是否报警、道闸杆是否被异物卡住。
4. 记录设备编号、位置、故障时间和现场照片。

## 常见故障与处理

| 现象 | 可能原因 | 处理动作 |
|---|---|---|
| 刷卡无反应 | 读卡器断电、卡片消磁、控制器离线 | 检查电源与网络，使用备用卡测试，重启控制器前先记录状态 |
| 门禁自动常开 | 门磁故障、消防联动、控制器异常 | 确认是否消防联动；非联动状态报维保 |
| 道闸不抬杆 | 地感线圈故障、遥控器无电、电机过热 | 检查地感与电源，使用手动释放装置疏导车辆 |
| 闸机夹人/异响 | 红外对射遮挡、机芯磨损 | 立即停用该通道，设置提示牌并报维保 |
| 访客二维码失效 | 二维码过期、网络中断、权限未下发 | 重新生成或改用人工登记，检查网络与权限同步 |

## 现场安全

- 道闸故障时优先保障车辆与行人通行安全，必要时开启人工通道。
- 禁止强行掰动道闸杆或攀爬闸机。
- 门禁失效涉及消防联动时，不得擅自恢复常闭状态，必须确认消防状态。
- 发现漏电、焦味、冒烟时立即断电并报修。

## 升级与转人工

- 整栋楼门禁同时失效；
- 消防联动异常或无法确认联动状态；
- 道闸/闸机夹人、伤人；
- 涉及重点区域（机房、消防通道、财务室）的门禁失效。

> 项目：IT 运维工单智能 Agent（agent-gongdan）

> 结论：**通过**。现有 `/api/v1/**` 与子 Agent 既有契约保持兼容，全量 E2E 回归通过。

---

## 1. 升级内容

### 1.1 有界任务拆解

- 对话 SSE 新增 `plan` / `step` 事件；
- 每步展示工具、参数摘要、状态、尝试次数、耗时；
- 幂等只读工具瞬时失败最多重试 1 次；
- `ticket_create` 等非幂等工具不重试；
- 配置：`AGENT_PLAN_EVENTS`、`AGENT_TOOL_RETRY_MAX`、`AGENT_MAX_STEPS`。

实际运行片段：

```json
event: plan
data: {"step":1,"max_steps":3,"actions":[{"tool":"ticket_query","arguments_summary":"状态=全部，关键词=无，条数=5"}]}

event: step
data: {"step":1,"action_index":0,"tool":"ticket_query","status":"SUCCESS","attempts":1,"duration_ms":27,"error_code":null}
```

### 1.2 可观测性

- 新增 `MetricsPort` + `MicrometerMetricsAdapter`；
- 指标：任务状态/耗时、队列深度、活跃线程、对话 token/耗时、工具调用；
- 新增 `GET /agent/v1/metrics/summary`（内部令牌 + ADMIN）；
- 聚合来源：`agent_task`、`chat_message`、`chat_tool_call`，不新增采集表。

实际运行片段：

```json
{
  "agentTasks": {
    "total": 198,
    "successRate": 0.8737,
    "byStatus": {"SUCCEEDED": 173, "FAILED": 11, "CANCELLED": 14},
    "p95LatencyMs": 334
  },
  "chat": {
    "assistantMessages": 118,
    "inputTokens": 226768,
    "outputTokens": 21690,
    "avgLatencyMs": 2789,
    "p95LatencyMs": 4694
  },
  "toolCalls": {
    "total": 58,
    "byTool": {"ticket_query": 13, "ticket_create": 27}
  }
}
```

Actuator 实测：

- `agent_task_total` 存在多组 `capability/status` 标签；
- `agent_task_queue_depth = 0`。

### 1.3 跨 Agent 传参预留

- Task 请求新增：`parentTaskId`、`correlationId`、`contextRefs`、`budget`、`deadlineAt`；
- `V19` 迁移新增对应列与索引，无物理外键；
- 响应回显上述字段；
- Manifest / Agent Card 升至 `0.6.0`；
- 新增 `DownstreamAgentPort` 与禁用适配器，默认不发请求。

## 4. 配置项

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENT_PLAN_EVENTS` | true | 是否下发 `plan` 事件 |
| `AGENT_TOOL_RETRY_MAX` | 1 | 幂等工具最大重试次数 |
| `AGENT_MAX_STEPS` | 3 | 工具循环上限 |
| `AGENT_DOWNSTREAM_ENABLED` | false | 下游 Agent 调用开关（当前无实现） |

| `AGENT_METRICS_LATENCY_SAMPLE_LIMIT` | 10000 | P95 样本上限 |

## 6. 仍存在的边界

1. `deadlineAt` / `budget` 仅持久化，不强制中断；
2. 指标聚合实时查库，未接 Prometheus/指标库，无看板与告警；
3. 任务 `inputTokens/outputTokens/costMicros` 仍未回填，当前任务能力基本不调用 LLM；
4. `DownstreamAgentPort` 仅冻结契约，未实现真实 HTTP 调用；
5. 无通用 Planner、多 Agent 编排、持久化 MQ 与崩溃恢复；
6. 契约测试尚未接入 CI 门禁。
